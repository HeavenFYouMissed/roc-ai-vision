# SapiMouse

[Permalink: SapiMouse](https://github.com/margitantal68/sapimouse#sapimouse)

SapiMouse - a new dataset for Mouse Dynamics (2020)

Repository for paper: SapiMouse: Mouse Dynamics-based User Authentication Using Deep Feature Learning

## SapiMouse dataset

[Permalink: SapiMouse dataset](https://github.com/margitantal68/sapimouse#sapimouse-dataset)

- Data collection software: [https://mousedynamicsdatalogger.netlify.app](https://mousedynamicsdatalogger.netlify.app/)
- Raw data: [https://ms.sapientia.ro/~manyi/sapimouse/sapimouse.html](https://ms.sapientia.ro/~manyi/sapimouse/sapimouse.html)
  - First session: S3 (3 minutes)
  - Second session: S1 (1 minute)
  - 120 subjects (92 male, 28 female)
  - log file lines: \[timestamp, button, state, x, y\]

## Raw features folder: input\_csv\_mouse

[Permalink: Raw features folder: input_csv_mouse](https://github.com/margitantal68/sapimouse#raw-features-folder-input_csv_mouse)

- step 1: first order differences (absolute value) - \|dx\|,\|dy\|
- step 2: segmentation into fixed-sized blocks (128)

## Authentication measurements

[Permalink: Authentication measurements](https://github.com/margitantal68/sapimouse#authentication-measurements)

- split the dataset into 2 subsets
\\* subset 1: subjects 1 .. 72 (60%)
\\* subset 2: subjects 73 ..120 (40%)

- step 1: feature learning (training a fully convolutional neural network, see TRAINED\_MODELS) using subset 1

- step 2: creating a One-class SVM model for each subject from subset 2
