## What is BORIS

[BORIS](https://www.boris.unito.it/) ( **B** ehavioral **O** bservation **R** esearch **I** nteractive **S** oftware) is an easy-to-use event logging software for video/audio coding and live observations. BORIS is a free and open-source software available for GNU/Linux, Windows and MacOS. Functions include but not limited to:

- Coding of video and audio files
- Event logging for live observations
- Coding from picture directories
- Exclusion matrix for mutually exclusive behaviors definition
- Transition matrix

## Accessing BORIS

BORIS is a freely available, open-source software platform. No purchase or license is required for access.
