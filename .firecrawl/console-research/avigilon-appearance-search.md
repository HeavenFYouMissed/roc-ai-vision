For Enterprise Edition


If you have video analytics cameras with the AvigilonAppearance Search feature enabled, you can search your site for persons or vehicles of interest.

## Searching by Description

If you have a physical description of a person or vehicle of interest, start an AvigilonAppearance Search query. Searching for vehicles by description requires the ACC Server software version 7.2 or later.

You can select as many or few search criteria as you want. The system ranks results that match all descriptions higher.

When searching for video in both day and night scenes, avoid using color as a search criteria. For example, the color red may appear gray at night.

1. In the New Task menu ![](https://docs-be.avigilon.com/bundle/acc-client-7-14/page/0Graphics/ACC7/ACC_menu.svg?_LANG=enus), click Appearances![](https://docs-be.avigilon.com/bundle/acc-client-7-14/page/0Graphics/ACC7/GlyphIconsSearchRecordedAppearance.svg?_LANG=enus) .
2. Select the person or vehicle icon.
3. Select the icons that best represent the person or vehicle description.
4. Click Date Range to set the date and time of your search.
5. Click Cameras to select the cameras you want to include in the search. By default, all cameras enabled with the AvigilonAppearance Search feature are selected.
6. Click Search.

Only the first 15 minutes of search results are displayed, regardless of the Date Range selected. Move the Search Results Graph window to view more results.

For more information, see [Avigilon Appearance Search Results](https://docs.avigilon.com/bundle/acc-client-7-14/page/using-acc/searching/appearance-results.htm).

## Searching Recorded Video

You can start a search for both people and vehicles of interest based on one instance in recorded video.

1. Complete a Motion, Thumbnails, Alarm or Identity search, or use the Timeline to find the person or vehicle of interest.
2. Click the bounding box around the person or vehicle and select one option:

   - ![](https://docs-be.avigilon.com/bundle/acc-client-7-14/page/0Graphics/ACC/AS_Search_After.png?_LANG=enus)**Find Appearances After This** — Search for instances of the person or vehicle after this event.
   - ![](https://docs-be.avigilon.com/bundle/acc-client-7-14/page/0Graphics/ACC/AS_Search_Previous.png?_LANG=enus)**Find Appearances Before This** — Search for instances of the person or vehicle before this event.
   - ![](https://docs-be.avigilon.com/bundle/acc-client-7-14/page/0Graphics/ACC7/ic_search.svg?_LANG=enus)**Additional Search Options** — Select cameras and a time range before performing the search.

Only the first or last 15 minutes of search results are displayed, regardless of the Date Range selected. Move the Search Results Graph window to view more results.

For more information, see [Avigilon Appearance Search Results](https://docs.avigilon.com/bundle/acc-client-7-14/page/using-acc/searching/appearance-results.htm).

## Searching by Uploaded Photo

Search for a person of interest by uploading a photo of the face or body. Or upload a photo of a vehicle of interest. If you have a photo with more than one object, separate them into individual photos. A photo with more than one object cannot be searched.

1. In the New Task menu ![](https://docs-be.avigilon.com/bundle/acc-client-7-14/page/0Graphics/ACC7/ACC_menu.svg?_LANG=enus), click Appearances![](https://docs-be.avigilon.com/bundle/acc-client-7-14/page/0Graphics/ACC7/GlyphIconsSearchRecordedAppearance.svg?_LANG=enus) .
2. Click ![](https://docs-be.avigilon.com/bundle/acc-client-7-14/page/0Graphics/ACC7/ic_photo_upload.PNG?_LANG=enus) in the Appearance Search Options window.
3. Click Choose File or drag and drop the file from your desktop or folder. The accepted formats are .jpg, .jpeg, .bmp, .gif, tif and .tiff.
      The photo is automatically cropped, and if searched, is retained for a specific amount of time. For more information, see [Identity Data Retention](https://docs.avigilon.com/bundle/acc-client-7-14/page/system-management/servers/data-retention.htm).

4. Search for the person or vehicle in video footage:

      1. Click Date Range to set the date and time of your search.
      2. Click Cameras to select the cameras you want to include in the search. By default, all cameras enabled with the AvigilonAppearance Search feature are selected.
      3. Optional. Fill out the **Reason for Search**.
      4. Click Search.

For more information, see [Avigilon Appearance Search Results](https://docs.avigilon.com/bundle/acc-client-7-14/page/using-acc/searching/appearance-results.htm).
