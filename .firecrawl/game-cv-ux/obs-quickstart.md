## Get Started in 5 Easy Steps

| ### 1\. Run the Auto-Configuration Wizard<br>![The Auto-Configuration Wizard window](https://obsproject.com/media/pages/kb/quick-start-guide/0a7db409d3-1767489958/auto-config-wizard-1.png) | First things first, let's start by setting up the best settings for your recordings and streams. The **Auto-Configuration Wizard** optimises OBS Studio for your needs, whether you're streaming fast-paced gameplay or recording high-fidelity video.<br>It takes into account what _you_ want to do in OBS Studio, your computer's hardware resources, and your network conditions (if you're streaming).<br>The wizard shows the first time you run OBS Studio. If you wish to use it again, click on the **Tools menu → Auto-Configuration Wizard**. |
| ### 2\. Add Sources to your Scenes<br>![Sources menu](https://obsproject.com/media/pages/kb/quick-start-guide/bb9f5b282f-1767489968/add-sources-menu.png) | When you start OBS Studio, you start with a blank scene by default. You can add all kinds of **Sources** — to show images, text, video, your webcam, game play, desktop, etc.

At the bottom of the main window is the Sources Dock. Click on the + symbol to add a source of your choice. Here are a few basic Sources to get you started:

|  |  |
| --- | --- |
| [![Display Capture](https://obsproject.com/kb/sources-guide/window.png)](https://obsproject.com/kb/display-capture-sources) | [Display Capture Source](https://obsproject.com/kb/display-capture-sources) and [Window Capture Source](https://obsproject.com/kb/window-capture-sources) for Windows and Linux, and [macOS Screen Capture Source](https://obsproject.com/kb/macos-screen-capture-source) for macOS — capture your desktop or a single window |
| [![Game Capture](https://obsproject.com/kb/sources-guide/gamepad.png)](https://obsproject.com/kb/game-capture-source) | [Game Capture](https://obsproject.com/kb/game-capture-source) (Windows only) to capture 3D games with the highest performance |
| [![Video Capture](https://obsproject.com/kb/sources-guide/camera.png)](https://obsproject.com/kb/video-capture-source) | [Video Capture Source](https://obsproject.com/kb/video-capture-sources) to capture your webcam and/or capture cards |

##### For more information on the various sources, check the [Sources Guide](https://obsproject.com/kb/sources-guide) |
| ### 3\. Set up your Audio<br>![Audio Mixer](https://obsproject.com/media/pages/kb/quick-start-guide/46fb6ccabe-1767489976/audio-meters.png) | By default, OBS Studio is set to capture your desktop audio and microphone. You can verify this by looking at the volume meters in the Audio Mixer (pictured left) at the bottom of the main OBS Studio window.<br>If they aren't moving, or you suspect the wrong device is being captured, click on **Settings → Audio** and select the devices manually.<br>![Settings window showing global audio devices](https://obsproject.com/media/pages/kb/quick-start-guide/04ae1466fe-1767489972/settings-audio-devices.png) |
| ### 4\. Test your Settings<br>![Controls Dock showing the Start Streaming and Start Recording buttons](https://obsproject.com/media/pages/kb/quick-start-guide/0fa79f2a03-1767489971/controls-dock.png) | Double check that all your settings are how you want them in **Settings → Output**. Then, click Start Recording or Start Streaming on the Controls Dock (pictured left).<br>We **strongly** encourage running a test for a few minutes to make sure that there are no issues, rather than just jumping in to your first stream or recording. |
| ### 5\. There is no Step 5! | Once you're satisfied, you can go on to creating great content. That's all there is to it! |
