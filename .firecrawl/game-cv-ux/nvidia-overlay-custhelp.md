# Unable to bring up the NVIDIA app In-Game Overlay when pressing Alt+Z

Updated 12/14/2024 10:31 PM

Unable to bring up the NVIDIA app In-Game Overlay when pressing Alt+Z

* * *

Learn what to do if you are unable to open the NVIDIA App In-Game Overlay.

1\. Verify the NVIDIA overlay is enabled from the NVIDIA App -\> Settings panel as shown in the screenshot below:

![](http://nvidia.custhelp.com/rnt/rnw/img/enduser/aid_3386_01.png)

2\. If your PC came pre-installed with Microsoft Windows 10 N or Windows 11 N, you will need to install the Microsoft Windows Media Feature Pack.  For more information, visit:

[https://support.microsoft.com/en-us/windows/media-feature-pack-for-windows-n-8622b390-4ce6-43c9-9b42-549e5328e407](https://support.microsoft.com/en-us/windows/media-feature-pack-for-windows-n-8622b390-4ce6-43c9-9b42-549e5328e407)

Following the installation of Windows N Media Pack, reboot your PC and reinstall NVIDIA App:

[https://www.nvidia.com/en-us/software/nvidia-app/](https://www.nvidia.com/en-us/software/nvidia-app/)

3\. Update your NVIDIA display drivers.  NVIDIA recommends display driver 565.90 or higher when used with NVIDIA.  If you have an older driver installed, certain NVIDIA app features may not work.  You may download the latest Game Ready Driver from the URL below:

[https://www.nvidia.com/en-us/geforce/game-ready-drivers/](https://www.nvidia.com/en-us/geforce/game-ready-drivers/)
