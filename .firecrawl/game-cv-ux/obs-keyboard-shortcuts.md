# Keyboard Shortcuts

2021-08-25

## **General shortcuts**

| Shortcut | Windows/Linux | macOS |
| --- | --- | --- |
| Quit OBS Studio | Ctrl-Q | ⌘Q |
| Undo edit | Ctrl-Z | ⌘Z |
| Redo edit | Ctrl-Shift-Z | ⇧⌘Z |

## Sources List Shortcuts

### **Only usable when a source is selected**

**General**

| Shortcut | Windows/Linux | macOS |
| --- | --- | --- |
| Copy source | Ctrl-C | ⌘C |
| Paste source | Ctrl-V | ⌘V |
| Remove source | Del | ⌫ (Delete) |

**Order**

| Shortcut | Windows/Linux | macOS |
| --- | --- | --- |
| Move source **up** in sources list | Ctrl-Up | ⌘▲ |
| Move source **down** in sources list | Ctrl-Down | ⌘▼ |
| Move source to **top** of sources list | Ctrl-Home | Fn⌘◀︎ |
| Move source to **bottom** of sources list | Ctrl-End | Fn⌘▶︎ |

**Transform**

| Shortcut | Windows/Linux | macOS |
| --- | --- | --- |
| Edit transform | Ctrl-E | ⌘E |
| Reset transform | Ctrl-R | ⌘R |
| Fit to screen | Ctrl-F | ⌘F |
| Stretch to screen | Ctrl-S | ⌘S |
| Center to screen | Ctrl-D | ⌘D |

## Preview Window Shortcuts

### **Only active when a bounding box is selected in the preview window**

| Shortcut | Windows/Linux | macOS |
| --- | --- | --- |
| Nudge source **up** | Up | ▲ |
| Nudge source **down** | Down | ▼ |
| Nudge source **left** | Left | ◀︎ |
| Nudge source **right** | Right | ▶︎ |
| Crop a source | Hold Alt and drag the bounding box | Hold ⌥ and drag the bounding box |
| Stretch a source | Hold Shift and drag the bounding box | Hold ⇧ (Shift) and drag the bounding box |
| Temporarily disable source snapping (if enabled) | Hold Ctrl and drag the bounding box | Hold ⌘ and drag the bounding box |

### **Only active when the Preview is set to Fixed Scaling (canvas or output)**

| Shortcut | Windows/Linux | macOS |
| --- | --- | --- |
| Move preview | Hold Space and drag it with the (mouse) pointer cursor | Hold Space and drag it with the (mouse) pointer cursor |
| Zoom preview | Hold Space and scroll the mouse/trackpad | Hold Space and scroll the mouse/trackpad |

- Move preview: Hold space and drag it with your mouse
- Zoom preview: Hold space + mouse scroll wheel
