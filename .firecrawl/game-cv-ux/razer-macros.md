### How to create a macro

1. Plug a Razer Synapse-enabled product into your computer.

2. Open Razer Synapse 4.

3. Select "MACRO" > "New Macro".

![Select MACRO and New Macro](https://dl.razerzone.com/src2/1483/1483-1-en-v2.png)

**Note:** By default, macro profiles will be named Macro 1, Macro 2, and so on.

4. Rename your macro for easier identification.
1. Click on the macro to rename.
2. Click the ellipsis button then click “Rename”.

      ![Click the ellipsis button and then Rename](https://dl.razerzone.com/src2/1483/1483-2-en-v1.png)

3. Enter your desired macro name.

      ![Enter your desired macro name.](https://dl.razerzone.com/src2/1483/1483-3-en-v2.png)
5. Record your keystrokes or mouse functions to add to the macro.
1. Click the drop-down button next to RECORD.

      ![Click the drop-down button next to RECORD](https://dl.razerzone.com/src2/1483/1483-4-en-v1.png)

2. Set the delay functions and how the mouse movement is recorded. If you select Record Delay, there is a countdown before Razer Synapse 4 starts recording.

      ![Set the delay functions and how the mouse movement is recorded](https://dl.razerzone.com/src2/1483/1483-5-en-v1.png)

3. Click “RECORD”.

      ![Start recording](https://dl.razerzone.com/src2/1483/1483-6-en-v2.png)

4. Click “STOP” to stop recording.

      ![Stop recording](https://dl.razerzone.com/src2/1483/1483-7-en-v1.png)

5. Click “SAVE” to save your recorded macro.

      ![Save recording](https://dl.razerzone.com/src2/1483/1483-8-en-v1.png)

Once your macro is saved, you can then assign it to any applicable Razer Synapse-enabled product.

### How to delete a macro

**Note:** This will delete all data in the macro.

1. Click on the ellipsis button of the macro you wish to delete.

2. Select "Delete".

![Select delete](https://dl.razerzone.com/src2/1483/1483-9-en-v1.png)

3. Click "DELETE".

![Click delete](https://dl.razerzone.com/src2/1483/1483-10-en-v2.png)

### How to create a macro

1. Plug a Razer Synapse 3-enabled product into your computer.

2. Open Razer Synapse 3.

3. Select "MACRO".

![Razer Synapse 3 macro tab settings window](https://dl.razerzone.com/OSvC/1483-1-EN-v1.png)

4. Click on the plus icon "+".

![Razer Synapse 3 window showing where to add a macro](https://dl.razerzone.com/OSvC/1483-2-EN-v1.png)



**Note:** By default, macro profiles will be named Macro 1, Macro 2, and so on. Rename your macro for easier identification.
1. Click on the macro to rename.
2. Click on the checkmark to save changes.

      ![Razer Synapse 3 window showing how to rename a macro](https://dl.razerzone.com/OSvC/1483-3-EN-v1.png)
5. Select a macro to start adding input sequences.

![Razer Synapse 3 window with an on-screen instruction to start inputting actions](https://dl.razerzone.com/OSvC/1483-4-EN-v1.png)


There are two ways to create a macro:

1. Record – records your keystrokes or mouse functions which will be added to the macro.
2. Insert – manually insert keystrokes or mouse functions to the macro.

**Record**

1. Click on "Record".

![Razer Synapse pane showing how to start recording a macro](https://dl.razerzone.com/OSvC/1483-5-EN-v1.png)

2. Set the delay functions and how the mouse movement is recorded. If you select Record Delay, there is a 3-second countdown before Razer Synapse 3 starts recording.

![Razer Synapse 3 three-second countdown dialogue box](https://dl.razerzone.com/OSvC/1483-6-EN-v1.png)

3. Click "START" when you are ready to record your macro.

4. Click "STOP" after you finished recording your macro.


Your macro is automatically saved. You can then assign it to any applicable Razer Synapse 3-enabled product.

**Insert**

1. Click "Insert".

![Razer Synapse 3 pane showing where to insert actions](https://dl.razerzone.com/OSvC/1483-7-EN-v1.png)

2. Select an action:
   - Keystroke
   - Mouse Button
   - Text
   - Run Command
3. Set macro properties on the right-side section of the screen.

4. Input an applicable function.

![Razer Synapse 3 pane showing where to add a function](https://dl.razerzone.com/OSvC/1483-8-EN-v1.png)



You can also set a delay before initiating the next action.

![Razer Synapse 3 pane showing where to add a delay](https://dl.razerzone.com/OSvC/1483-9-EN-v1.png)


Your macro is automatically saved. You can then assign it to any applicable Razer Synapse 3-enabled devices.

For a guide on how to assign macros, see [How to assign macros on Razer Synapse 3-enabled Razer products](https://mysupport.razer.com/app/answers/detail/a_id/1751 "How to assign macros on Razer Synapse 3-enabled Razer products").

### How to delete a macro

1. Click on the ellipsis button of the macro you wish to delete.

2. Select "Delete".

**Note:** This will delete all data in the macro.

![Razer Synapse 3 window showing how to delete a macro](https://dl.razerzone.com/src/1483-10-EN-v1.png)

3. Click "DELETE".

![Razer Synapse 3 dialogue box](https://dl.razerzone.com/src/1483-11-EN-v1.png)
